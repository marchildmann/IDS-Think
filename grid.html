Responsive Considerations

Content Grid Caveat

The content grid data-grid="fluid" does not clamp spans automatically.

At md (8 cols): span=8 fills the row, but span=16 overflows.
At sm (4 cols): span=4 fills the row, but span=8 overflows.

Safe Span Values

Use spans that divide evenly into all column counts:

  • span=1 — works everywhere
  • span=2 — works everywhere
  • span=4 — works everywhere (full row at sm)
  • span=8 — lg only (full row at md)
  • span=full — always safe
